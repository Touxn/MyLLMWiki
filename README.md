# MyLLMWiki

一套可在 Obsidian 中使用的个人知识库模板。你保存原稿，AI 按 [AGENTS.md](AGENTS.md) 的规则整理摘要、关联主题，并在回答问题时标明出处。

## 从第一篇资料开始

1. 下载或克隆仓库，在 Obsidian 中将这个文件夹打开为仓库。
2. 把自己的文章放进 `原始资料/我的原创/`，把收藏的文章放进 `原始资料/他人精选/`。随手记下的想法放进 `原始资料/灵感库/`，图片等附件放进 `attachments/`。
3. 用能访问该文件夹的 AI 助手执行这句话：「请先读 AGENTS.md，再整理新增资料，生成知识条目并更新索引和日志。」

整理后，从 `index.md` 浏览知识条目，也可以直接问 AI：「这篇文章有哪些值得复用的方法？请附原文出处。」

## 文件和目录怎么用

| 文件或目录 | 用途 |
| --- | --- |
| [README.md](README.md) | 模板使用指南。从这里了解如何打开知识库、放入第一份资料并开始整理。 |
| [AGENTS.md](AGENTS.md) | AI 整理知识库时遵循的规则，包括原稿保护、增量整理、来源引用和需要确认的改动。 |
| [index.md](index.md) | 知识索引。初始为空，首次整理后从这里按主题查找知识页。 |
| [log.md](log.md) | 整理日志。初始为空，每次完成整理后追加本次处理的资料、版本指纹、改动页面与待确认事项。 |
| [attachments/](attachments/) | 存放笔记引用的图片等附件。 |
| [原始资料/](原始资料/) | 保存原稿和灵感。自己的作品放在[我的原创](原始资料/我的原创/)，收藏的他人作品放在[他人精选](原始资料/他人精选/)，随手记的想法放在[灵感库](原始资料/灵感库/)。 |
| [知识条目/](知识条目/) | 存放整理后的知识页。[资料摘要](知识条目/资料摘要/)按来源记录要点和出处，[概念与方法](知识条目/概念与方法/)按主题汇总步骤和适用条件，[人物、工具与平台](知识条目/人物、工具与平台/)按对象归集相关记录。 |

各子目录中的 `.gitkeep` 用于让 Git 保留空目录，下载模板后可以直接往相应目录添加资料。
