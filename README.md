# MyLLMWiki

一套可在 Obsidian 中使用的个人知识库模板。你保存原稿，AI 按 [AGENTS.md](AGENTS.md) 的规则整理摘要、关联主题，并在回答问题时标明出处。

## 从第一篇资料开始

1. 下载或克隆仓库，在 Obsidian 中将这个文件夹打开为仓库。
2. 把自己的文章放进 `原始资料/我的原创/`，把收藏的文章放进 `原始资料/他人精选/`。随手记下的想法放进 `原始资料/灵感库/`，图片等附件放进 `attachments/`。
3. 用能访问该文件夹的 AI 助手执行这句话：「请先读 AGENTS.md，再整理新增资料，生成知识条目并更新索引和日志。」

整理后，从 `index.md` 浏览知识条目，也可以直接问 AI：「这篇文章有哪些值得复用的方法？请附原文出处。」
